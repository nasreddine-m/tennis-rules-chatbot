L'assistant du règlement de tennis (ITF)

Posez une question sur les règles du jeu, le score, les fautes ou l'équipement. Les réponses sont tirées du règlement officiel et de guides ITF, sources à l'appui.

Quelques exemples de questions

  • Combien de temps dure l'échauffement ?
  • Que dit le Code sur les fautes de pied ?
  • Comment résoudre un désaccord sur le score ?
Assistant basé sur un pipeline RAG (n8n + Supabase + OpenAI). Les réponses hors règlement du tennis sont refusées.
